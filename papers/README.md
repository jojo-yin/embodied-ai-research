# papers — 论文精读

**命名**：`paper_001/`、`paper_002/`…… 编号**连续，不跳号**。

每篇论文一个目录，内部结构：

    paper_001/
    ├── paper_notes.md     精读十二问的书面作答
    ├── reproduction.md    复现过程、命令、踩坑记录
    ├── config/            实验配置文件（必须入库）
    ├── code/              相关代码或补丁
    ├── experiments/       在此论文基础上的扰动实验
    ├── results/           结果、图表、日志（*.log 不入库）
    └── conclusion.md      我的结论与可迁移的东西

**纪律**：`paper_notes.md` 必须**逐条书面回答**下面的十二问，不允许只写摘要；`conclusion.md` 没写，这篇论文视为**未完成**。

## 精读十二问模板

    # Paper 001 — <标题>

    ## 基本信息
    - 会议/年份：
    - 作者与机构：
    - 代码链接：
    - 笔记日期：

    ## 精读十二问
    1.  研究问题是什么？
    2.  为什么这个问题重要？
    3.  Related Work 有哪些？
    4.  作者解决了什么不足？
    5.  Method 是什么？
    6.  核心创新在哪里？
    7.  Dataset 是什么？
    8.  Experiment 怎么设计？
    9.  Baseline 是什么？
    10. Metric 是什么？
    11. Ablation 怎么做？
    12. 作者的结论是否被实验支持？证据的边界在哪里？

    ## 三句话总结
    - 贡献：
    - 证据：
    - 边界：

    ## 可迁移的东西
    - 对我自己的研究有什么可复用的思想 / 方法 / 工程技巧？
